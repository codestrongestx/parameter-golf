# Tokenizer Wildcard

Use it for:

- tokenizer changes
- BPB verification work tied to tokenizer changes

- keep this fully separate from the mainline
- do not mix tokenizer experiments into the official-neural history

Store curated results under:

- `tokenizer_wildcard/results/YYYY-MM-DD_<gpu>_<run_id>/`
